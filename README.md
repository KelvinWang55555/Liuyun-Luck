# 周易 · 占筮 —— 个人手机端应用

纯静态网站，无需任何服务器。部署到 GitHub Pages 后，手机浏览器随时可开。

## 功能

- **每日一卦**：按日期确定性生成当日卦象（同一天打开结果一致），含卦辞、象曰、简释与动爻提示
- **金钱课**：模拟三枚铜钱连摇六次起卦，自动判定老阴/老阳变爻并给出变卦
- **数字起卦**（梅花易数）：输入上卦数、下卦数、动爻数（可按时辰自动取动爻）
- **心问一签**：默念所问之事，随机起一卦
- **六十四卦典**：全部 64 卦的卦画、卦辞、大象传、白话简释
- **拼音标注**：64 卦卦名全部带拼音；卦辞中生僻字自动加注音（如 姤(gòu)、筮(shì)、虩(xì)）
- **命理（生辰八字）**：输入出生日期与时辰，自动排四柱八字、五行分布、生肖、日主旺衰简判与喜用神，附幸运色/方位/数字。日柱以 1949-10-01 甲子日为锚点推算（已与黄历核验一致）；年柱以立春为界、月柱按节气近似划分
- **个人化运势**：保存生辰后，每日一卦自动显示契合度评分、卦象五行与日主的生克关系及开运提示；「命理」页有独立的今日运势卡
- **占筮历史**：记录保存在手机本地（localStorage），随时回看
- **每日热点**：GitHub Actions 每天早上 7:30（北京时间）自动抓取新闻写入 `news.json`，页面自动展示

## 部署到 GitHub Pages（约 3 分钟）

1. 登录 GitHub，新建一个仓库（如 `zhouyi`），Public 可见
2. 把本目录的全部文件（含 `.github` 文件夹）上传到仓库
   - 网页上传：仓库页 → **Add file → Upload files**，把 `index.html`、`data.js`、`bazi.js`、`app.js`、`news.json` 拖进去，再把 `.github/workflows/news.yml` 也传上去（注意 `.github` 是隐藏文件夹，网页上传时需手动创建路径）
   - 或命令行：
     ```bash
     git init && git add -A && git commit -m "init zhouyi app"
     git remote add origin https://github.com/<你的用户名>/zhouyi.git
     git push -u origin main
     ```
3. 仓库页 → **Settings → Pages** → Build and deployment 来源选 **Deploy from a branch**，Branch 选 `main` / `(root)`，保存
4. 约 1 分钟后访问 `https://<你的用户名>.github.io/zhouyi/` 即可
5. 手机浏览器打开该网址 → 分享 → **添加到主屏幕**，就像一个 App

## 热点更新

- 首次部署后进入仓库 **Actions** 页，点击 `daily-news` 工作流 → **Run workflow** 手动跑一次，即可立刻生成今日热点
- 之后每天北京时间早上 7:30 自动运行；GitHub Actions 定时任务可能有 ±15 分钟左右的延迟，属正常现象
- 抓取源为「每天 60 秒读懂世界」公开 API（`60s-api.viki.moe` 等），可在 `news.yml` 中修改 `ENDPOINTS` 换源

## 本地使用

双击 `index.html` 即可使用全部占筮功能；热点功能需部署后联网加载。

## 说明

- 占筮结果仅为传统文化参考，数据均存于本机，不收集任何信息
- 卦画约定：六爻自下而上，1=阳爻，0=阴爻；64 卦按文王卦序排列
